# Framing Effect 2.0

An online jsPsych experiment on the framing effect in risky choice. Participants answer gain- or loss-framed problems (e.g. the Asian Disease problem). Each problem offers a sure option, a risky option, and a neutral "flip a coin" option. After each choice, participants rate their confidence from 0 to 100. If they choose the netural option, a follow-up asks them to pick between the sure and risky options.

## Structure

- `index.html`: entry point; loads jsPsych and the plugins
- `frame-neutrality_v02.js`: experiment timeline and stimuli
- `img/`: instruction images
- `jspsych/`: jsPsych 8.0.2, a custom slider plugin, and the Pavlovia plugin

## Running

- **Platform:** hosted on Pavlovia and recruited through Prolific.
